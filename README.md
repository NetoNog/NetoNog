## Sobre

Desenvolvo sites, sistemas e automações sob medida com **Next.js, TypeScript e PostgreSQL**. Do banco de dados à interface, entrego software rápido, seguro e fácil de manter, com comunicação direta durante todo o projeto.

- Stack tipada de ponta a ponta: Next.js, React, TypeScript, Node.js e PostgreSQL
- Cuido do que não aparece na tela: modelagem de dados, Row Level Security, validação de entradas e desempenho
- Experiência anterior em suporte e infraestrutura de TI, o que me faz construir pensando em quem opera o software no dia a dia
- Atendimento remoto para todo o Brasil
